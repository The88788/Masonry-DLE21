# Masonry для DLE 21.0

Адаптивный журнальный шаблон со светлой и тёмной темами. Проверенная версия CMS: **DLE 21.0**.

## Возможности

- Сетка публикаций в 3 / 2 / 1 колонку, мобильное меню, поиск и диалоги авторизации.
- Статья, комментарии и цитирование через штатный редактор DLE.
- Обычная постраничная навигация; размер страницы настраивается в CMS.
- Локальный Montserrat, SVG-иконки, служебные страницы и формы.
- Обложка из поля poster или первого изображения статьи; без изображения — заглушка.

## Установка

Скопируйте Masonry в templates, выберите шаблон в DLE и очистите кэш. Полная инструкция — [INSTALL.md](INSTALL.md). CMS, база данных и демонстрационные фотографии в сборку не входят. Сторонние модули не требуются.
